# PataFeliz – tienda dropshipping (mascotas)

Tienda estática en `site/`. Cada producto en `site/products.json` apunta a un Stripe Payment Link.

## Puesta en marcha
1. Stripe: crear un Payment Link por producto y pegarlo en `link`.
2. Hosting: publicar `site/` (Cloudflare Pages / Netlify / GitHub Pages, gratis).
3. Proveedor: CJ Dropshipping o Printful/Printify (personalizados). Pedir muestra antes de vender.
4. Cuando entra un pedido en Stripe, hacerlo en el proveedor con la dirección del cliente.

## Costes
| Concepto | Coste |
|---|---|
| Hosting | 0 € |
| Dominio | ~10 €/año |
| Stripe | 1,5 % + 0,25 € por venta (UE), sin cuota fija |
| Proveedor (CJ/Printful) | solo el coste del producto por pedido; muestras ~30–60 € |
| Publicidad (TikTok/Meta) | presupuesto de prueba recomendado 150–300 € |
